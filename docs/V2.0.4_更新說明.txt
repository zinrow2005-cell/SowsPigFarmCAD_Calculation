王泰山畜牧場 CAD 工作台 V2.0.4｜配置自動檢查

新增：
1. 上方「⚑ 配置檢查」按鈕，可獨立開啟檢查面板，不必進入編輯模式。
2. 自訂最小設施間距、東側水平餘寬警示門檻，保存於本機。
3. 偵測 1230 七項設施的相互重疊、相接／共牆、與1230參考外框的超界／距離。
4. 對位於東側直線邊界區間的設施，顯示東側水平餘寬警示；不是已確認的通道淨寬。
5. 顯示問題清單、CAD 圖上異常定位記號，可勾選隱藏記號。
6. 配置編輯套用、復原、重設後自動刷新檢查結果。

限制：
- 目前只針對1230七項規劃設施；地界參考外框非實測法律界線。
- 最短幾何距離不考慮設備突出、門扇開啟、車輛迴轉、坡度與管線。
- 警示數值可自行設定，並非法規最低距離；實際施工、建蔽率及界址仍須專業人員核對。
- 原本的配置編輯功能仍阻止新重疊與超界調整。原始CAD與DXF保持不變。

驗證：
- 全部 JavaScript 檔案語法檢查。
- Node 隔離沙盒實測初始七設施共293.86 m²、基礎問題清單生成、刻意移動堆肥舍至重疊位置後偵測出重疊。
- 介面開關 / 清單呈現已做事件級單元測試。
- Chromium 瀏覽器在本執行環境禁止載入本機與 loopback 網址，故無法宣稱已完成瀏覽器及手機端驗收。
