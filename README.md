# 虎尾畜牧場｜CAD 圖面查詢 V2.2.2

## 開啟
完整解壓縮 ZIP，雙擊 `index.html`（或由瀏覽器開啟）。無須 Node.js、登入或網路。請勿只複製 HTML；assets 資料夾須一起保留。若瀏覽器限制本機檔案下載或儲存，可將整個 measure 資料夾部署至靜態網站（例如 GitHub Pages）。

## 日常操作
- 圖面查詢：點選設施看名稱、面積、邊線；搜尋或快速定位；全場恢復視野。滾輪/雙指縮放，拖曳平移。預設小字體。
- 面積計算：點選多區加入或取消，清單可個別移除、全選、清空。聯集面積扣除重疊；平方公尺及坪數供參考。
- 空地比：選擇原場、1230 或合併基地，使用相應預設或自行選取遮蔽區。上限預設 80%，可自行修改；未選區不代表實地沒有遮蔽。水利地 1226 不計入基地，明示空地及場外水溝不計入遮蔽試算。
- 顯示設定：名稱、面積、兩者或純圖面；字體及尺寸標註可調整。手機直式底部資訊欄；橫式右側。全螢幕為最大化工作區模式。
- 匯出：圖面列印與分享 → A3/A4、直/橫、全場/目前視野、統計內容 → SVG、PNG 或瀏覽器列印/另存 PDF。CSV 可用試算表開啟；DXF 為參考交付；JSON 用於保存核對及設定、換機匯入。建議定期備份 JSON，瀏覽器儲存不等同雲端備份。
- 進階：基地完整性核對、原始/校正模式、尺寸核對、補畫牆段及區塊。補畫區塊不自動列入基地遮蔽試算。

## 檔案
index.html 為入口；assets 為程式及資料；cad 為原始與參考 DXF；release.json 為版本資訊；docs/history 為歷史紀錄（非新版操作指引）。保留所有運行資產與原始 CAD；不更動校正幾何。正式定版指功能凍結，不代表地籍或法規核定。


### V1.7.8 文字排版

## PWA 安裝（V1.7.8）
將 measure 目錄完整部署至 HTTPS 網站（例如 GitHub Pages）。iPhone／iPad 使用 Safari 開啟 index.html，分享 → 加入主畫面；Android 使用 Chrome 選單 → 安裝應用程式／加入主畫面。首次連線成功後，Service Worker 將快取系統程式與圖面，支援離線。Windows 直接開啟 index.html 仍可使用，但 file:// 不支援 PWA 安裝或 Service Worker。舊主畫面圖示可能需移除後重新加入。先備份核對 JSON。

## V1.7.8 手機效能
拖曳、雙指縮放期間每畫面最多更新一次視角，尺寸及智慧標註於手勢結束或短暫停止後更新。PWA 快取版本同步更新；舊版請完全關閉後重新開啟。

## V1.7.8 周界尺寸精簡
主畫面合併連續近共線段，獨立不足 1 m 的短邊預設收合；仍可點選反白。圖面查詢及周界表顯示最多兩位小數，原始座標及核對資料保留精度。進階核對逐原始段保存，不將合併長度寫入首段。

## V1.8.2 更新
