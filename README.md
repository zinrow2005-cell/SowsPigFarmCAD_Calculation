## 本版目的

以使用者提供的 `虎尾場_CAD_base_2026-11-11.dxf` 為唯一幾何底圖，讓現場人員按區塊核對尺寸後，直接匯出 **可供代書在 CAD 軟體繼續繪圖的 DXF**。

**整面牆長包含中途門洞的寬度，不把門洞另行扣除或列為獨立牆長。只有轉角需要另分段丈量。** 但原 DXF 的牆體線段與門洞幾何維持原樣，輸出時不會把門封起來。

## 三欄工作方式

1. **左欄｜全場區塊與牆段**：可選產房 A～D、公豬舍、採精室／儲物室、麻布袋洗曬區、新女豬育成與配種舍整棟、妊娠舍、採精／儲物走道、西側縱向走道及外圍牆線。
2. **中欄｜CAD 原圖**：點選區塊或牆。預設勾選「整面邊線（含門）」；點線時優先選取目前區塊的一面完整邊線。若要查證原始 DXF 的短牆段，取消勾選即可。
3. **右欄｜尺寸編輯**：切到「整面邊線含門」依轉角間的整段長度填寫，按「✓ 已核」標示已確認。輸入後會保留 CAD 參考值以便比對。

> **重要**：部分不規則區塊含非實體牆的參考界線；必須依現場及代書確認界線性質。CAD 座標算出的尺寸並不等於現場實測，勾選「已核」代表使用者確認，並非經政府或地政機關核定。

## 交給代書的方式

當每一面牆都核對完畢：

1. 按「↓ 匯出代書 DXF」或右欄「下載可編輯 DXF（含核對尺寸）」。
2. 再按「核對 JSON」保存完整的核對狀態、數字、備註及與 DXF 來源雜湊值。
3. 視需要下載 CSV 供對帳。**最建議一併交付 DXF 與核對 JSON**，讓代書能對照哪一項已核、哪一項尚未核。

### DXF 輸出的規則

- 原始 2026-11-11 DXF 含 **1,116 個圖元**，此次新增線後正式底圖共 **1,117 個圖元**，所有原始牆線、門洞、門扇、欄位及其他圖層都保留，座標單位沿用公尺（`$INSUNITS = 6`）。
- `HW_VERIFIED_DIM`：已核對的完整邊線尺寸。尺寸線、延伸線和文字屬於可編輯的 LINE / TEXT 參考圖元；這些不是會自動更新的關聯式 AutoCAD DIMENSION 物件。
- `HW_PENDING_DIM`：未核對尺寸，**預設不輸出**；只有額外勾選時才輸出橘色圖層且文字明確標為 `PEND`。
- `HW_FIELD_SKETCH`：工作台內自行補畫的牆段，作為參考線，**不能冒認為原始 CAD 已有實際牆**。
- 原圖被門洞拆開的短牆段尺寸，**預設不另外輸出**，避免和整面含門長度重複。需要比對原圖時才自行勾選「加入原圖短牆段的已核尺寸」。
- 勾「只輸出目前區塊的尺寸標註」後，原始 CAD 全場底圖仍完整保留，只限制本次新增的尺寸標註範圍。
- 當沒有核對完成的尺寸時，匯出按鈕會提示；仍可選擇只交付原始 CAD，但**不能宣稱尺寸已核**。

### 現場修正數值與 CAD 幾何的關係

當 CAD 參考長度為 30.676m、現場核對為 41.371m 時，匯出檔會顯示 **41.371m 的已核尺寸文字**，但 **原牆線仍是原始幾何 30.676m**。這是供代書參照重畫／調整的工作圖，不會擅自拉長原牆線、使其他門洞或設備位置錯亂。代書應再檢查相鄰牆線、接點、比例、方向與相關圖層後修改幾何。

## 資料安全

- 本版工作台維持與既有「設備配置系統」分離的 `measure/` 子目錄，**不覆蓋原系統首頁或其照片／設備資料**。
- 填寫記錄會儲存在本機瀏覽器 LocalStorage，以原 DXF SHA256 識別。請定期下載 JSON；不同瀏覽器、離線檔與 GitHub 網站的本機儲存互不相通。
- 匯出核對 JSON 不會直接改寫原始 DXF；若要變更原 CAD 幾何，仍需 CAD 人員處理。
